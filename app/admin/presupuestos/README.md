# Módulo de Presupuestos

Módulo profesional de presupuestos integrado en el panel de administración.

## Estructura

- Dashboard principal
- Solicitudes recibidas desde la web (tasador de clientes)
- Clientes
- Presupuestos oficiales
- Biblioteca de precios
- Fotografías
- Plantillas PDF
- Historial
- Configuración

## Fases

- [x] Fase 1: Dashboard + Layout + Conexión Supabase
- [ ] Fase 2: Configuración del tasador (precios base)
- [ ] Fase 3: Formulario de clientes (`/solicitar-presupuesto`)
- [ ] Fase 4: Ver solicitudes en admin
- [ ] Fase 5: Clientes + Presupuestos
- [ ] Fase 6: Constructor oficial
- [ ] Fase 7: Biblioteca + Fotografías
- [ ] Fase 8: PDF profesional

## Colores del módulo

- Verde principal: `#10B981`
- Fondo: `#0b0b0a`
- Texto: `#f3f0e9`

## Conexión Supabase

Usa `lib/presupuestos/supabase.ts` como cliente central.
